Web components — new for the browser

The web dashboard reuses every token, badge, card and button from the mobile app unchanged (see the Tokens sheet). What's genuinely new is navigation shape: a phone has a thumb-reach tab bar and no public marketing surface at all; a browser dashboard has room for a persistent sidebar, and gets a logged-out Home/About the mobile app never needed.
